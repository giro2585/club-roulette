# Клаб рулетка

Сайт с рулеткой призов, личным кабинетом и магазином за бонусы («ККоин»).

## Запуск

Нужен Node.js 22.13 или новее. Базу данных ставить не нужно, она создаётся сама (SQLite, файл `data/roulette.db`).

```bash
npm install
ADMIN_PASSWORD=свой_пароль npm start
# открыть http://localhost:3000
```

Администратор: логин `admin`, пароль из `ADMIN_PASSWORD` (по умолчанию `admin123`, обязательно смените перед запуском для людей).
Пароль задаётся только при первом запуске, когда база ещё пустая.

Переменные окружения: `PORT` (по умолчанию 3000), `DATA_DIR` (папка для базы), `ADMIN_PASSWORD`.

## Что есть

- **Рулетка**: лента карточек, спин стоит 30 ККоин. Приз выбирается на сервере по весам, остаток приза уменьшается при каждом выигрыше, закончившийся приз больше не выпадает.
- **Типы призов**: `bonus` (сразу на баланс), `promo` (выдаётся промокод), `item` (физический приз, ждёт выдачи админом по коду).
- **Личный кабинет**: ID, звание по рейтингу, спины за период, баланс, история выигрышей, покупок и всех операций по балансу.
- **Награда за вход**: 7 дней подряд, при пропуске серия начинается заново.
- **Задания**: автоматические (N спинов, N покупок, N дней подряд) и ручные (админ подтверждает).
- **Рейтинг** по числу спинов за двухнедельный период.
- **Магазин скидок**: промокоды на скидку с ценой в ККоин и остатком, покупатель получает промокод.
- **Админка** (`/#/admin`): призы и шансы, остатки, магазин, задания, выдача призов и заказов, заявки, начисление/списание ККоин, настройки (цена спина, бонус новичкам, награды за вход, название валюты).

## Хостинг

Подойдёт любой хостинг с Node.js и постоянным диском (VPS, Render, Railway, Fly.io и т.п.). Папку `data/` нужно держать на постоянном диске, иначе база обнулится при перезапуске.

### Установка на VPS одной командой

На чистом сервере Ubuntu 22.04/24.04 (от root):

```bash
curl -fsSL https://raw.githubusercontent.com/giro2585/club-roulette/main/deploy/install.sh | DOMAIN=ваш-домен.ru ADMIN_PASSWORD='свой_пароль' bash
```

Без домена уберите `DOMAIN=...`, сайт откроется по IP-адресу. С доменом HTTPS настраивается автоматически (домен должен указывать на IP сервера). Повторный запуск той же команды обновляет сайт до последней версии из GitHub, база сохраняется.
